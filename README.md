# Password Manager

# 🛡️ Pattern-Based Encrypted Password Manager

This is a Python-based graphical password manager that uses a **pattern-drawing login system** and **username-based encryption** to securely store and retrieve your credentials.

---

## 📌 Features

- 🧩 **Pattern Drawing Login**: Instead of typing a password, users draw a 4-point pattern on a 4x4 grid.
- 🔐 **Per-User Encryption**: Each user's stored passwords are encrypted using a key derived from their username.
- 🗂️ **Credential Management**: Store and retrieve IDs and passwords for websites and apps.
- 🧪 **Basic File Storage**: Credentials are stored in local text files (one for login and one for saved entries).
